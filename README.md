# SQL Trainer

Learn SQL on real plant-floor data. A mobile-first practice app: 7 lessons from SELECT to JOINs, a real in-browser SQLite query engine (sql.js, bundled — works fully offline), result checking, hints, solutions, a schema browser, and a free playground.

- No account, no server. Lesson progress is stored on-device.
- Package: com.jakinscraft.sqltrainer
